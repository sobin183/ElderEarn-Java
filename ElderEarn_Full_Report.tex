\textbf{ABSTRACT}
\end{center}
\vspace{1cm}
\textbf{ElderEarn -- Skill Sharing and Micro-Earning Platform} is an enterprise web application engineered to bridge the socio-economic and generational divide between senior citizens possessive of profound vocational, professional, and cultural expertise and younger generations seeking personalized, affordable mentorship. Global demographic trends indicate an unprecedented rise in the elderly population, frequently accompanied by involuntary retirement, reduced financial autonomy, and acute social isolation. Concurrently, students and young professionals encounter high financial barriers in commercial learning portals and struggle to access individualized, real-world practical knowledge.

The proposed system addresses this dual challenge by establishing a secure, dignified, and decentralized digital marketplace. Elder citizens register as verified mentors, publish structured skill profiles across technical, artistic, artisanal, and linguistic disciplines, and upload curriculum videos. Learners browse specialized domains, evaluate mentor credentials, enroll in curated modules, and book one-on-one consultation sessions. To ensure absolute financial integrity and mutual trust, the system features a dual-ledger Digital Wallet integrated with an Escrow Payment mechanism, guaranteeing that mentor payouts are released only upon successful session delivery and learner verification. A direct interactive chat module facilitates seamless communication, question resolution, and scheduled consultation prep.

Developed using enterprise Java technologies including Java Servlets and JavaServer Pages (JSP) hosted on the Apache Tomcat application server, backed by an ACID-compliant MySQL relational database, ElderEarn adheres to a clean Model-View-Controller (MVC) architectural pattern. The user interface is strictly customized with high-contrast accessibility standards, intuitive navigation typography, and minimal cognitive load, specifically catering to elderly users with varying degrees of digital literacy.

The project directly advances the United Nations Sustainable Development Goals, specifically \textbf{SDG 8: Decent Work and Economic Growth} by providing flexible, home-based micro-earning avenues for senior citizens, and \textbf{SDG 4: Quality Education} by democratizing access to lifelong experiential learning and vocational mastery. Additionally, the platform supports \textbf{SDG 10: Reduced Inequalities} and \textbf{SDG 3: Good Health and Well-Being} by fostering active aging, cognitive engagement, and intergenerational empathy.

\section{Project Overview}
In the contemporary global landscape, rapid technological transformation, industrial automation, and changing demographic structures have fundamentally altered the relationship between generations. On one hand, humanity is experiencing a remarkable demographic shift termed the ``Silver Tsunami'' or the aging transition. Advances in modern healthcare, sanitation, and nutritional standards have significantly increased life expectancy across both developed and developing societies. However, societal paradigms regarding employment, retirement, and economic productivity have failed to evolve concurrently. Senior citizens, possessing decades of accumulative professional experience, artisanal craftsmanship, historical knowledge, and vocational expertise, often find themselves abruptly disconnected from active economic participation upon reaching arbitrary institutional retirement ages. This sudden disengagement frequently precipitates severe socio-psychological consequences, including profound loneliness, social alienation, loss of personal agency, cognitive decline, and acute economic dependency.

Simultaneously, the younger demographic comprising secondary school students, university undergraduates, entry-level professionals, and vocational apprentices faces an entirely different set of pressing socioeconomic challenges. Contemporary educational systems are frequently criticized for emphasizing rote theoretical instruction at the expense of authentic, real-world practical mastery. Commercial continuing-education platforms, massive open online courses (MOOCs), and vocational coaching institutes operate predominantly on transactional, high-cost subscription models. These platforms feature passive, pre-recorded mass lectures devoid of meaningful human mentorship, personalized diagnostic feedback, or cultural nuance. Consequently, young aspirants seeking specialized knowledge in areas such as financial planning, traditional handicrafts, legal consultancy, language acquisition, coding fundamentals, and administrative navigation find themselves priced out or underserved by generic pedagogical delivery.

\textbf{ElderEarn -- Skill Sharing and Micro-Earning Platform} is conceived, engineered, and deployed as a strategic sociotechnical intervention to reconcile these parallel systemic dilemmas. ElderEarn operates as an intergenerational, peer-to-peer knowledge exchange ecosystem and digital micro-earning marketplace. The core architecture of the platform enables retired professionals, elderly artisans, and skilled senior citizens to register as dignified subject-matter mentors. Through an accessible, highly ergonomic web interface, senior mentors can document their areas of expertise, design structured modular syllabi, upload instructional video demonstrations, schedule direct consultative appointments, and deliver individualized guidance to motivated learners.

In return for their pedagogical contributions, senior citizens generate legitimate, supplementary micro-earnings credited directly to their proprietary in-platform digital wallets. The financial mechanism is anchored by a secure Escrow transaction architecture: when a student books a session or enlists in a premium course, the associated fee is debited from the student's wallet and placed into a secure escrow reserve. Upon verified completion of the educational session and mutual confirmation, the funds are instantly released to the mentor's withdrawable balance. By transforming passive retirement into an active, productive, and intellectually stimulating chapter of life, ElderEarn transforms the traditional perception of the elderly from dependent economic burdens into indispensable societal repositories of wisdom, mentorship, and continuous value creation.

\section{Objectives}
The overarching mission of ElderEarn is to construct an inclusive, accessible, and financially transparent digital ecosystem that facilitates intergenerational knowledge transmission while empowering senior citizens through flexible, dignified micro-earning opportunities. 

To achieve this foundational mission, the project defines the following specific, measurable, and technically rigorous operational objectives:
\begin{enumerate}[label=\arabic*.]
    \item \textbf{Develop an Accessible and Age-Friendly User Interface:} To design and implement a web-based front-end interface strictly compliant with Web Content Accessibility Guidelines (WCAG 2.1 AA), incorporating scalable high-contrast typography, prominent visual affordances, intuitive navigational taxonomies, and forgiving error-prevention mechanisms tailored specifically to senior citizens with varying degrees of digital literacy.
    \item \textbf{Implement Dual-Role Registration and Profile Verification:} To engineer a robust role-based authentication and authorization mechanism that enables seamless onboarding for both senior mentors and student learners, supporting credential verification, biographical summaries, and portfolio showcase features.
    \item \textbf{Create a Modular Skill and Multimedia Content Management Engine:} To provide senior mentors with intuitive tools to define multi-part instructional courses, structure pedagogical modules, and securely upload multimedia learning materials (including video demonstrations, reference notes, and downloadable assets).
    \item \textbf{Deliver an Intelligent Course Catalog and Discovery System:} To implement an indexed, multi-criteria search and discovery subsystem that allows students to filter available skill offerings based on category, difficulty level, mentor rating, pricing tier, and scheduling availability.
    \item \textbf{Build an Integrated Direct Messaging and Consultation Dispatcher:} To engineer a real-time, asynchronous, and synchronous communication pipeline enabling direct inquiries, pre-session clarifications, scheduling coordination, and personalized feedback between mentors and students.
    \item \textbf{Architect a Secure Escrow-Backed Digital Wallet System:} To construct an ACID-compliant digital ledger subsystem incorporating dual-party escrow reserves that securely holds learner course fees until verified session delivery, thereby mitigating transactional fraud and guaranteeing punctual mentor compensation.
    \item \textbf{Establish a Transparent Reputation and Peer-Review Framework:} To implement a bidirectional rating, review, and feedback system allowing students to evaluate mentor pedagogical quality, session punctuality, and instructional depth, fostering an atmosphere of mutual accountability and trust.
    \item \textbf{Deploy Comprehensive Administrative Governance Tools:} To build an administrative dashboard providing system operators with real-time telemetric monitoring, course moderation capabilities, dispute resolution interfaces, and financial ledger audit trails.
    \item \textbf{Promote Active Aging and Cognitive Stimulation:} To provide retired individuals with a structured digital medium for social immersion, continuous intellectual engagement, purposeful community involvement, and psychological fulfillment.
    \item \textbf{Advance the United Nations 2030 Sustainable Development Goals:} To measurably contribute toward SDG 8 (Decent Work and Economic Growth) and SDG 4 (Quality Education) through demonstrable metrics of financial inclusion and decentralized vocational learning.
\end{enumerate}

\section{Scope of the Project}
The architectural and functional scope of ElderEarn is calibrated to deliver an enterprise-grade prototype capable of operating in production-like university and municipal community settings. The scope is delineated across several operational boundaries:

\begin{itemize}
    \item \textbf{Functional Scope:} The platform encompasses user registration, encrypted credential storage, role-specific session state management, course creation, multi-part video uploads, search indexing, schedule booking, direct in-browser messaging, digital wallet management, escrow transaction orchestration, and administrative oversight.
    \item \textbf{Demographic Scope:} The system is designed to accommodate two primary user personas: senior mentors (typically individuals aged 55 and above seeking purposeful post-retirement engagement and secondary income) and student learners (ranging from high school pupils to working adults seeking customized skill acquisition). A third administrative role oversees system compliance and governance.
    \item \textbf{Financial Scope:} The current implementation incorporates a closed-loop digital wallet model. Simulated payment gateways and escrow ledgers manage wallet top-ups, session fee locks, escrow releases, platform fee deductions, and withdrawal requests. This architecture provides complete end-to-end accounting fidelity without exposing sandbox users to external regulatory liability.
    \item \textbf{Technical Scope:} The system is engineered utilizing a 3-tier enterprise architecture. The presentation tier leverages HTML5, CSS3, JavaScript (ES6+), and Bootstrap 5. The middle enterprise application tier is powered by Java Servlets and JavaServer Pages (JSP) executing within an Apache Tomcat servlet container. Persistent storage and ACID transactional integrity are maintained via a MySQL 8.0 relational database engine connected through Java Database Connectivity (JDBC).
    \item \textbf{Out of Scope:} Real-time peer-to-peer WebRTC video conferencing (currently managed via integrated external meeting hyperlinks), automated biometric identity verification, and multi-currency international forex settlements are excluded from the current baseline release and positioned within the strategic future scope.
\end{itemize}

\section{Overview of Sustainable Development Goal}
In September 2015, the United Nations General Assembly formally adopted the 2030 Agenda for Sustainable Development, comprising 17 Sustainable Development Goals (SDGs) and 169 associated targets. This comprehensive global framework represents a universal call to action to eradicate extreme poverty, protect planetary ecosystems, foster social equity, and ensure peace and prosperity for all human populations by the year 2030. Unlike historical development frameworks that focused primarily on traditional economic metrics like Gross Domestic Product (GDP), the SDGs recognize that sustainable social development requires an integrated, multidimensional approach that balances economic prosperity, social inclusion, and environmental sustainability.

A central philosophical tenet of the 2030 Agenda is the pledge to ``Leave No One Behind''. This pledge explicitly acknowledges that vulnerable, marginalized, and historically underrepresented demographics—including senior citizens, youth, persons with disabilities, and low-income communities—must be actively integrated into modern social and economic frameworks. As the world confronts rapid digitalization and demographic aging, innovative digital technologies serve as vital catalysts for realizing these global commitments. Information and Communication Technologies (ICT), when engineered with human-centric, ethical, and inclusive principles, possess the transformative capability to eliminate physical barriers, decentralize knowledge distribution, and construct resilient community-based economic paradigms.

\subsection{SDG 8: Decent Work and Economic Growth}
United Nations SDG 8 aims to ``Promote sustained, inclusive and sustainable economic growth, full and productive employment and decent work for all.'' The global economy is confronted with the dual challenge of an aging demographic whose productive capacities are prematurely discarded, alongside high rates of youth underemployment. ElderEarn directly addresses:
\begin{itemize}
    \item \textbf{Target 8.5:} By 2030, achieve full and productive employment and decent work for all women and men, including for young people and persons with disabilities, and equal pay for work of equal value. ElderEarn establishes a home-based, non-coercive micro-consulting platform where elderly citizens determine their own hours, set fair session fees, and monetize lifetime expertise without physically demanding travel.
    \item \textbf{Target 8.6:} By 2020, substantially reduce the proportion of youth not in employment, education or training (NEET). By connecting young apprentices with seasoned veterans in diverse vocational, technical, and artistic trades, ElderEarn provides practical skill enhancement that improves youth employability at a fraction of traditional coaching costs.
\end{itemize}

\subsection{SDG 4: Quality Education}
SDG 4 seeks to ``Ensure inclusive and equitable quality education and promote lifelong learning opportunities for all.'' Conventional pedagogical structures are frequently rigid, theory-heavy, and geographically restricted. ElderEarn advances:
\begin{itemize}
    \item \textbf{Target 4.4:} Substantially increase the number of youth and adults who have relevant skills, including technical and vocational skills, for employment, decent jobs and entrepreneurship.
    \item \textbf{Target 4.7:} Ensure that all learners acquire the knowledge and skills needed to promote sustainable development, cultural diversity, and lifelong learning. Through direct mentor-student interaction, cultural heritage, artisanal techniques, and real-world domain insights are organically transferred across generations.
\end{itemize}

\section{Problems Addressed}
ElderEarn systematically dismantles five major societal and structural dysfunctions that plague modern urban and semi-urban communities:

\begin{enumerate}[label=\arabic*.]
    \item \textbf{Involuntary Post-Retirement Economic Disenfranchisement:} The majority of workforce participants in organized and unorganized sectors face rigid, mandatory retirement ages. In the absence of comprehensive social security cushions, particularly in developing economies, retirees face sudden income depletion, inflation-driven financial stress, and reliance on family support.
    \item \textbf{Social Isolation, Loneliness, and Geriatric Mental Health Crises:} The transition into retirement often involves a catastrophic loss of professional identity, day-to-day social interaction, and mental challenge. Longitudinal psychological studies consistently identify chronic loneliness in seniors as a primary risk factor accelerating Alzheimer's disease, dementia, clinical depression, and cardiovascular mortality.
    \item \textbf{The Crisis of Unaffordable and Impersonal Youth Vocational Training:} Commercial e-learning giants have commoditized online education into passive, mass-produced video repositories. Learners pay substantial subscription fees but experience dismal completion rates (under 10\%) due to a total lack of individualized coaching, diagnostic feedback, and mentorship accountability.
    \item \textbf{Irreversible Loss of Cultural, Artisanal, and Traditional Knowledge:} Rapid modernization has disconnected younger cohorts from indigenous crafts, traditional horticultural knowledge, local culinary arts, classical instrumentation, and artisanal mechanics. When senior practitioners pass away without apprentices, centuries of intangible cultural capital vanish.
    \item \textbf{Intergenerational Polarization and Communication Breakdown:} Modern societal segregation places youth in competitive academic or digital silos while isolating elderly citizens in retirement homes or empty-nest households. This lack of organic contact generates mutual stereotyping, emotional detachment, and generational alienation.
\end{enumerate}

\section{Contribution of the Proposed Project towards the SDG(s)}
ElderEarn bridges these societal chasms by providing a practical, scalable, and software-mediated framework:
\begin{itemize}
    \item \textbf{Decentralized Micro-Earning Pipeline:} Senior citizens register their specialized offerings and establish per-course or per-hour consultation tariffs. By engaging just 5 to 10 hours per week, retired individuals generate dignified supplementary income to cover personal healthcare, hobbies, and independent living expenses.
    \item \textbf{Bespoke Intergenerational Mentorship:} Instead of generic video libraries, ElderEarn pairs curious students directly with master practitioners. A student seeking advice on tax compliance, civil engineering field logistics, carpentry joinery, or classical violin interacts with a professional who spent 40 years in that specific discipline.
    \item \textbf{Protected Financial Architecture via Escrow:} By introducing an automated escrow ledger, ElderEarn eliminates mutual payment anxieties. Learners are confident their funds are protected until lessons are delivered satisfactorily, and mentors are guaranteed instant payout upon session verification.
    \item \textbf{Cognitive Rehabilitation through Social Immersion:} Teaching, structuring course outlines, responding to chat questions, and engaging with young minds stimulates neural plasticity, revitalizes self-worth, and instills a profound renewed sense of purpose among elderly mentors.
\end{itemize}

\section{Expected Social and Environmental Impact}
The multidimensional implementation of ElderEarn yields substantial positive externalities across community, economy, and environment:

\subsection{Social and Community Impact}
The primary social dividend of ElderEarn is the restoration of community cohesion. By establishing mutual reliance between disparate age cohorts, the platform cultivates empathy, dismantles ageist societal prejudices, and creates genuine intergenerational friendships. \section{Functional Specifications}
The functional specifications define the operational capabilities, procedural workflows, and user-facing interactions executed across the platform modules:

\subsection{User Authentication and Role Management}
\begin{itemize}
    \item \textbf{Registration and Onboarding:} Users register under designated roles—Senior Mentor or Student Learner—submitting their full name, email address, contact telephone, password, and brief biographical summary.
    \item \textbf{Secure Credential Hashing:} Passwords submitted during registration or authentication are cryptographically salted and hashed using SHA-256 prior to database storage, preventing plain-text exposure in persistent records.
    \item \textbf{Session Lifecycle Management:} Upon valid credential authentication, the server establishes an HTTP session container (`HttpSession`) storing the user's unique identifier, role, and security token. Session expiration policies automatically invalidate idle sessions after 30 minutes.
    \item \textbf{Role-Based Access Control (RBAC):} Servlet filters intercept all incoming HTTP requests, inspecting session attributes to ensure that restricted mentor administration pages cannot be accessed by students, and vice versa.
\end{itemize}

\subsection{Skill Offering and Video Content Management}
\begin{itemize}
    \item \textbf{Course Curriculum Creation:} Senior mentors create structured learning modules by providing a course title, categorized domain (e.g., Gardening, Woodworking, Finance, Languages), comprehensive description, duration, and consultation fee.
    \item \textbf{Multimedia Video Demonstration Upload:} Mentors can upload high-definition video demonstrations illustrating core techniques. The system validates file MIME types (e.g., MP4, WebM), enforces size thresholds (up to 50 MB per module), generates unique sanitized server-side filenames, and updates the relational media registry.
    \item \textbf{Curriculum Management:} Mentors maintain complete autonomy to edit course descriptions, reorder instructional video chapters, update session fees, or archive obsolete courses.
\end{itemize}

\subsection{Course Catalog and Discovery Management}
\begin{itemize}
    \item \textbf{Dynamic Marketplace Exploration:} Students browse an open catalog displaying active skill offerings enriched with mentor biographies, average star ratings, enrolled student counts, and pricing badges.
    \item \textbf{Multi-Criteria Search and Filtering:} Real-time SQL filtering allows learners to search courses by keyword, filter by skill taxonomy, sort by instructor rating, or set maximum fee constraints.
    \item \textbf{Detailed Syllabus Inspection:} Learners can inspect comprehensive course syllabi, watch promotional introductory video snippets, read peer feedback reviews, and review mentor credentials before committing funds.
\end{itemize}

\subsection{Direct Gated Messaging and Mentorship Booking}
\begin{itemize}
    \item \textbf{In-Platform Messaging Pipeline:} A dedicated in-browser messaging module allows learners to initiate direct chat dialogues with mentors. Messages are timestamped, indexed, and displayed in an intuitive conversational thread.
    \item \textbf{Session Appointment Scheduling:} Learners propose convenient time slots for one-on-one consultation sessions. Mentors receive instant notifications on their dashboard, where they can approve, reschedule, or decline appointments based on personal availability.
    \item \textbf{Consultation Meeting Dispatch:} Confirmed appointments generate automated session passes containing topic agendas, preparation instructions, and secure external meeting links (e.g., Google Meet / Zoom).
\end{itemize}

\subsection{Digital Wallet and Escrow Payment Processing}
\begin{itemize}
    \item \textbf{Dual-Ledger Digital Wallet:} Each registered user possesses a dedicated digital wallet record tracking current available balance, locked escrow balance, and total cumulative earnings.
    \item \textbf{Simulation Gateway Top-Up:} Learners can top up their digital wallet balance through a simulated secure payment gateway providing debit/credit card and UPI mock interfaces.
    \item \textbf{Escrow Vault Locking Mechanism:} When a student books a session, the exact course tariff is immediately deducted from their available balance and placed into a locked `ESCROW_HELD` state. Neither the learner nor the mentor can withdraw this locked capital during the active booking lifecycle.
    \item \textbf{Automated Payout Disbursement:} Following verified session delivery, the student verifies completion (or an automated timeout window expires without disputes). The system triggers an atomic database transaction transferring the funds from `ESCROW_HELD` to the mentor's withdrawable `AVAILABLE_BALANCE`, minus a minimal 5\% platform maintenance fee.
    \item \textbf{Payout Withdrawal Requests:} Mentors can request withdrawals of their cleared micro-earnings to external bank accounts or UPI IDs, generating printable transaction receipts.
\end{itemize}

\subsection{Ratings, Reviews, and Quality Moderation}
\begin{itemize}
    \item \textbf{Verified Learner Reviews:} Only learners who have formally enrolled in a course or completed a consultation session are authorized to submit numerical star ratings (1 to 5 stars) and qualitative narrative reviews.
    \item \textbf{Dynamic Reputation Scoring:} A database trigger or application calculation dynamically recalculates the mentor's cumulative average rating upon every new review submission, ensuring accurate social proof.
    \item \textbf{Administrative Moderation:} System administrators possess global oversight to inspect reported reviews, flag inappropriate content, mediate financial escrow disputes, and suspend non-compliant accounts.
\end{itemize}

\subsection{Activity Diagram}
The Activity diagram models the end-to-end procedural workflow and decision pathways involved in publishing a course, booking a consultation, locking escrow funds, delivering instruction, and releasing mentor earnings.

\begin{figure}[H]
\centering
\includegraphics[width=0.88\textwidth]{actvity diagram.png}
\caption{Activity Diagram of ElderEarn Platform}
\end{figure}

The step-by-step operational sequence represented in Figure 5.2 proceeds as follows:
\begin{enumerate}[label=\arabic*.]
    \item \textbf{Course Publishing:} The senior mentor authenticates, navigates to the course creator interface, populates syllabus parameters, attaches video demonstration assets, and publishes the course to the public catalog.
    \item \textbf{Discovery and Selection:} The learner navigates the marketplace, executes keyword or categorical search, reviews the syllabus and mentor rating, and initiates a booking request.
    \item \textbf{Wallet Balance Check \& Escrow Locking:} The system evaluates whether the learner's available wallet balance is sufficient. If insufficient, a prompt directs the learner to the simulated top-up gateway. If sufficient, the system atomically deducts the fee and locks it in the escrow ledger.
    \item \textbf{Mentor Confirmation \& Interaction:} The mentor reviews the appointment slot, approves the session, and exchanges preparatory guidance via direct messaging.
    \item \textbf{Session Execution \& Escrow Release:} The consultation takes place. Upon completion, the student marks the session as satisfied. The escrow engine atomically transfers funds to the mentor's withdrawable balance (less the platform fee).
    \item \textbf{Feedback Submission:} The learner submits star ratings and narrative commentary, automatically updating the mentor's public reputation score.
\end{enumerate}

\section{User Interface Design}
User interface design is critical to the success of ElderEarn, given the unique ergonomic and cognitive needs of senior citizen users. The UI architecture adheres strictly to Web Content Accessibility Guidelines (WCAG 2.1 Level AA):

\begin{itemize}
    \item \textbf{Visual Ergonomics and Typography:} The interface utilizes a minimum base font size of 16px with proportional scaling up to 24px for subheadings and 32px for primary page headers. Typefaces with high legibility (e.g., Segoe UI, Roboto) are implemented with generous line-heights (1.6) to prevent visual fatigue among elderly mentors.
    \item \textbf{High-Contrast Color Semantics:} High-contrast ratios ($\ge 4.5:1$) are enforced across all text and interactive buttons. Primary actions (such as ``Publish Course'', ``Approve Booking'', ``Withdraw Funds'') use unambiguous color coding—deep sapphire blues, emerald greens for success states, and warm ambers for pending alerts—ensuring immediate visual recognition.
    \item \textbf{Forgiving and Generous Tap Targets:} Interactive form buttons, navigation links, and input elements are styled with a minimum touch dimension of $48 \times 48$ pixels, accommodating tremors, reduced motor dexterity, or touch-screen interactions common among seniors.
    \item \textbf{Explanatory Feedback and Error Prevention:} System actions that involve financial mutations or video deletions trigger explicit modal confirmation dialogues with clear plain-language explanations, eliminating accidental loss or unintended transactions.
\end{itemize}

\section{Implementation Overview}
System implementation is the critical phase where theoretical software architectures, relational database schemata, and ergonomic user interface designs are transformed into an operational, enterprise-grade software product. The implementation of ElderEarn follows a disciplined 3-tier enterprise architecture structured around the Model-View-Controller (MVC) design pattern:

\begin{itemize}
    \item \textbf{Presentation Tier (View):} Built using dynamic JavaServer Pages (JSP), custom JSTL tag libraries, HTML5 semantic elements, and modern CSS3 styled with the Bootstrap 5.3 framework. The view layer is strictly decoupled from business processing, responsible exclusively for DOM rendering, visual data presentation, and client-side form validation.
    \item \textbf{Application Logic Tier (Controller):} Implemented via standard Java Servlets (`javax.servlet.http.HttpServlet` / `jakarta.servlet.http.HttpServlet`) executing within the Apache Tomcat servlet container. Servlets intercept client HTTP requests, authenticate session states, parse multi-part form payloads, enforce business rules, orchestrate transactions, and dispatch forward requests to target JSP views.
    \item \textbf{Persistence Tier (Model):} Composed of plain Java Data Access Objects (DAOs) communicating with a MySQL 8.0 relational database via Java Database Connectivity (JDBC). Connection pooling ensures minimal overhead during concurrent transactions, while parameterized `PreparedStatement` executions eliminate SQL injection vulnerabilities.
\end{itemize}

\section{Implementation Procedure}
The procedural deployment of ElderEarn involves structured sequential milestones executed across development and testing environments:

\subsection{Database Schema Initialization and Migration}
The persistent foundation is established by executing comprehensive DDL scripts in MySQL 8.0. Foreign key constraints are enforced with strict referential integrity (`ON DELETE RESTRICT`, `ON UPDATE CASCADE`). Indexes are generated on frequently queried fields—such as `users.email`, `skills_courses.category`, and `wallet_transactions.txn_timestamp`—to guarantee sub-millisecond retrieval. Database user credentials are restricted through principle-of-least-privilege grant policies.

\subsection{Connection Pool Configuration}
To prevent database connection exhaustion under concurrent user traffic, connection pooling is managed via Apache Commons DBCP / Tomcat JDBC Pool. The connection pool maintains a pool of pre-allocated database connections, recycling connections upon servlet thread completion:

\begin{lstlisting}[language=Java, style=codeStyle]
Context initCtx = new InitialContext();
Context envCtx = (Context) initCtx.lookup("java:comp/env");
DataSource ds = (DataSource) envCtx.lookup("jdbc/ElderEarnDB");
Connection conn = ds.getConnection();
\end{lstlisting}

\subsection{Controller and Filter Deployment}
All servlets and security filters are declared using standard Java annotations (`@WebServlet`, `@WebFilter`, `@MultipartConfig`). The `AuthenticationFilter` intercepts every incoming HTTP request, inspecting the `HttpSession` for valid credentials and verifying that requested URL routes conform to the user's role authorization before allowing request traversal down the filter chain.

\subsection{User Training}
Given that ElderEarn serves a diverse user demographic that explicitly includes senior citizens who may experience apprehension or unfamiliarity with modern web interfaces, comprehensive, empathetic user training protocols are integrated into the implementation strategy:

\subsubsection{Senior Citizen Onboarding and Digital Empowerment}
\begin{itemize}
    \item \textbf{Step-by-Step Onboarding Wizards:} First-time senior mentors are guided through an interactive visual walkthrough explaining profile setup, microphone and webcam testing, and course publishing steps without technical jargon.
    \item \textbf{Video Production Best Practices Guide:} Mentors receive accessible, illustrated guidelines covering basic home video recording—such as positioning the smartphone camera at eye level, ensuring front-facing window illumination, minimizing background household noise, and structuring demonstrations into concise 5-minute modules.
    \item \textbf{Financial Literacy and Wallet Transparency:} To dispel anxiety regarding online financial transactions, senior mentors are provided with a visual guide demonstrating how the escrow mechanism guarantees their payment, how the wallet balance updates in real time, and how funds are transferred directly to their local bank accounts.
\end{itemize}

\subsubsection{Student Learner Orientation}
\begin{itemize}
    \item \textbf{Code of Conduct and Intergenerational Etiquette:} Learners are briefed on respectful, punctual communication when interacting with senior mentors, emphasizing active listening, preparatory reading, and thoughtful engagement during consultation sessions.
    \item \textbf{Platform Navigation and Booking Transparency:} Students are trained on utilizing search filters, managing wallet top-ups, and understanding the escrow release lifecycle to foster mutual accountability.
\end{itemize}

\subsection{System Maintenance}
To ensure long-term operational resilience, data security, and adaptability, ElderEarn establishes formalized procedures spanning the four foundational categories of software maintenance:

\subsubsection{Corrective Maintenance}
Corrective maintenance addresses software defects, edge-case runtime exceptions, and environmental anomalies discovered during live operation:
\begin{itemize}
    \item Implementation of centralized server-side logging using `java.util.logging` / Log4j, recording stack traces with severity classifications (INFO, WARN, SEVERE).
    \item Automated exception handlers (`error404.jsp`, `error500.jsp`) that display friendly, reassuring recovery instructions to users while logging technical diagnostics for developers.
    \item Periodic inspection of database transaction logs to detect and resolve potential deadlocks or incomplete escrow transactions.
\end{itemize}

\subsubsection{Adaptive Maintenance}
Adaptive maintenance ensures the software continues to function harmoniously as external software environments, third-party libraries, and browser standards evolve:
\begin{itemize}
    \item Regular testing against new browser releases (Chrome, Edge, Firefox, Safari) to ensure uninterrupted CSS layout compliance and JavaScript execution.
    \item Updating underlying Java runtime dependencies and JDBC drivers to align with evolving LTS security patches and TLS 1.3 cryptographic protocols.
    \item Adjusting responsive CSS breakpoints to accommodate newly emerging tablet and smartphone screen form factors.
\end{itemize}

\subsubsection{Perfective Maintenance}
Perfective maintenance focuses on performance optimization, code refactoring, and enhancing user experience based on real-world feedback:
\begin{itemize}
    \item Implementing browser-side caching headers for static assets (images, stylesheets, JavaScript libraries) to accelerate page load times for low-bandwidth users.
    \item Optimizing relational database queries through index tuning, query execution plan analysis (`EXPLAIN`), and denormalizing aggregate counters where appropriate.
    \item Enhancing video compression pipelines to minimize storage footprints while preserving crystal-clear audio-visual clarity for instructional demos.
\end{itemize}

\subsubsection{Regular and Preventative Maintenance}
Preventative maintenance encompasses routine operational hygiene to avert catastrophic system failures:
\begin{itemize}

    \item Automated rotation and archiving of Tomcat server access logs and transaction logs to prevent server storage saturation.
    \item Quarterly vulnerability scans and dependency audits using tools like OWASP Dependency-Check to identify and mitigate known common vulnerabilities and exposures (CVEs).

\end{itemize}

\section{Limitations}
While ElderEarn successfully fulfills its foundational functional and architectural specifications, providing a secure, accessible, and dignified skill-sharing platform, several technical, operational, and infrastructural limitations exist in the current prototype:

\begin{itemize}
    \item \textbf{Bandwidth and Video Streaming Constraints:} The current implementation stores uploaded instructional video demonstrations directly on the local server filesystem and streams them via HTTP partial content range requests. In low-bandwidth rural or semi-urban environments, higher-resolution video playback may experience buffering delays in the absence of adaptive bitrate streaming (e.g., HLS or MPEG-DASH) or cloud-distributed Content Delivery Networks (CDNs).
    \item \textbf{External Virtual Meeting Link Integration:} Live one-on-one consultation sessions currently rely on external virtual conferencing services (such as Google Meet, Zoom, or Microsoft Teams) linked through the platform. This requires users to transition between browser tabs and third-party software rather than engaging within an integrated, in-browser video call environment.
    \item \textbf{Simulated Financial Payment Gateway:} To adhere to academic sandbox constraints and prevent regulatory licensing liabilities during prototype testing, the digital wallet and escrow ledger utilize a simulated payment top-up mechanism rather than a live commercial banking gateway (such as Razorpay, Stripe, or Cashfree).
    \item \textbf{Manual Identity and Credential Verification:} Mentor credentials and artisanal expertise are currently audited and verified through administrative manual review. As user volume expands, manual auditing may present an operational bottleneck.
    \item \textbf{Web-Centric Architecture:} Although the web interface is fully responsive across mobile viewports, the platform is not yet packaged as a native Android or iOS application, precluding features such as push notifications, hardware-accelerated video capture, and offline playback.
\end{itemize}

\section{Future Scope}
The architectural modularity of ElderEarn provides a fertile foundation for significant future enhancements and advanced technological integration:

\begin{itemize}
    \item \textbf{AI-Powered Mentor-Learner Recommendation Engine:} Implementing machine learning algorithms (such as collaborative filtering and natural language semantic embeddings) to analyze learner interests, academic curricula, and learning pace, automatically pairing students with the most suitable senior mentors.
    \item \textbf{Native In-Browser WebRTC Live Video Conferencing:} Incorporating real-time peer-to-peer audio/video streaming directly within the browser using WebRTC (Web Real-Time Communication) and WebSocket signaling servers. This will enable synchronized interactive whiteboards, screen sharing, and automatic session recording without external third-party tools.
    \item \textbf{Multilingual Voice-Assisted Navigation:} Integrating speech-to-text and text-to-speech conversational AI agents (supporting regional Indian languages such as Malayalam, Hindi, Tamil, and Telugu) to allow non-English speaking elderly artisans to navigate the platform, publish courses, and respond to queries through natural voice commands.
    \item \textbf{Decentralized Digital Credentialing (Verifiable Credentials):} Leveraging blockchain-anchored digital badges and smart contracts to issue tamper-proof, cryptographic certificates of completion to learners, while immutably recording mentor reputation scores across decentralized ledgers.
    \item \textbf{Native Mobile Application Development:} Packaging the platform as cross-platform native mobile applications (using Flutter or React Native) featuring background push notifications, biometric fingerprint authentication, and camera-integrated video recording utilities.
\end{itemize}

\section{Conclusion}
The **ElderEarn -- Skill Sharing and Micro-Earning Platform** demonstrates how compassionate, human-centric software engineering can effectively reconcile two of the most pressing socioeconomic challenges of the modern era: the involuntary economic marginalization and social isolation of senior citizens, and the crisis of unaffordable, impersonal vocational training confronting younger generations.

By uniting an accessible, age-friendly web presentation tier with an enterprise Java backend, an ACID-compliant MySQL relational persistence layer, and an automated Escrow financial ledger, ElderEarn establishes a trusted, transparent, and dignified digital marketplace. Retired professionals and master craftspeople are revitalized as esteemed societal mentors, generating meaningful supplementary micro-income from the comfort of their homes while stimulating their cognitive vitality and emotional well-being. Concurrently, motivated students and apprentices gain affordable, individualized, real-world practical mastery outside impersonal corporate training structures.

In doing so, ElderEarn transcends traditional e-learning paradigms to serve as an intergenerational social bridge. The project stands as a practical, scalable, and compelling realization of United Nations **SDG 8: Decent Work and Economic Growth** and **SDG 4: Quality Education**, validating the principle that modern digital technologies, when engineered with social purpose and ethical empathy, can build inclusive, resilient, and compassionate communities where no generation is left behind.

import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import javax.servlet.http.HttpSession;

@WebServlet("/LoginServlet")
public class LoginServlet extends HttpServlet {
    private static final long serialVersionUID = 1L;
    private UserDAO userDAO;

    @Override
    public void init() {
        userDAO = new UserDAO();
    }

    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        String email = request.getParameter("email");
        String password = request.getParameter("password");

        // Input boundary validation
        if (email == null || email.trim().isEmpty() || 
            password == null || password.trim().isEmpty()) {
            request.setAttribute("errorMessage", "Email and Password are required.");
            request.getRequestDispatcher("login.jsp").forward(request, response);
            return;
        }

        try {
            // Cryptographic password hashing (SHA-256)
            String hashedPassword = hashPassword(password);
            User authenticatedUser = userDAO.authenticateUser(email.trim(), hashedPassword);

            if (authenticatedUser != null) {
                // Initialize secure session container
                HttpSession session = request.getSession(true);
                session.setAttribute("user", authenticatedUser);
                session.setAttribute("userId", authenticatedUser.getUserId());
                session.setAttribute("role", authenticatedUser.getRole());
                session.setMaxInactiveInterval(1800); // 30 minutes

                // Role-specific routing dispatch
                if ("MENTOR".equalsIgnoreCase(authenticatedUser.getRole())) {
                    response.sendRedirect("mentorDashboard.jsp");
                } else if ("STUDENT".equalsIgnoreCase(authenticatedUser.getRole())) {
                    response.sendRedirect("studentDashboard.jsp");
                } else if ("ADMIN".equalsIgnoreCase(authenticatedUser.getRole())) {
                    response.sendRedirect("adminDashboard.jsp");
                } else {
                    response.sendRedirect("index.jsp");
                }
            } else {
                request.setAttribute("errorMessage", "Invalid email or password.");
                request.getRequestDispatcher("login.jsp").forward(request, response);
            }
        } catch (Exception ex) {
            ex.printStackTrace();
            request.setAttribute("errorMessage", "Server error: " + ex.getMessage());
            request.getRequestDispatcher("login.jsp").forward(request, response);
        }
    }

    private String hashPassword(String password) throws NoSuchAlgorithmException {
        MessageDigest md = MessageDigest.getInstance("SHA-256");
        byte[] hash = md.digest(password.getBytes("UTF-8"));
        StringBuilder hexString = new StringBuilder();
        for (byte b : hash) {
            String hex = Integer.toHexString(0xff & b);
            if (hex.length() == 1) hexString.append('0');
            hexString.append(hex);
        }
        return hexString.toString();
    }
}

    private static final long serialVersionUID = 1L;
    private ChatDAO chatDAO;

    @Override
    public void init() {
        chatDAO = new ChatDAO();
    }

    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        HttpSession session = request.getSession(false);
        if (session == null || session.getAttribute("userId") == null) {
            response.sendError(HttpServletResponse.SC_UNAUTHORIZED);
            return;
        }

        int senderId = (int) session.getAttribute("userId");
        int receiverId = Integer.parseInt(request.getParameter("receiverId"));
        String messageText = request.getParameter("messageText");

        // Input sanitization against XSS
        if (messageText == null || messageText.trim().isEmpty()) {
            response.sendError(HttpServletResponse.SC_BAD_REQUEST, "Message text is empty.");
            return;
        }
        String sanitizedText = messageText.replace("<", "&lt;").replace(">", "&gt;").trim();

        ChatMessage chatMsg = new ChatMessage(senderId, receiverId, sanitizedText);
        boolean success = chatDAO.saveMessage(chatMsg);

        if (success) {
            response.setStatus(HttpServletResponse.SC_OK);
            response.getWriter().write("{\"status\":\"SENT\"}");
        } else {
            response.sendError(HttpServletResponse.SC_INTERNAL_SERVER_ERROR, "Database write failure.");
        }
    }
}

package com.elderearn.controller;

import com.elderearn.dao.WalletDAO;
import java.io.IOException;
import java.math.BigDecimal;
import javax.servlet.ServletException;

import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import javax.servlet.http.HttpSession;

@WebServlet("/WalletServlet")
public class WalletServlet extends HttpServlet {
    private static final long serialVersionUID = 1L;
    private WalletDAO walletDAO;

    @Override
    public void init() {
        walletDAO = new WalletDAO();
    }

    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        HttpSession session = request.getSession(false);
        if (session == null || session.getAttribute("userId") == null) {
            response.sendRedirect("login.jsp");
            return;
        }

        int userId = (int) session.getAttribute("userId");
        String action = request.getParameter("action");

        try {
            if ("topup".equalsIgnoreCase(action)) {
                BigDecimal amount = new BigDecimal(request.getParameter("amount"));
                if (amount.compareTo(BigDecimal.ZERO) <= 0) throw new IllegalArgumentException("Invalid topup amount.");
                walletDAO.creditAvailableBalance(userId, amount, "Simulated Gateway Deposit");
                response.sendRedirect("studentWallet.jsp?status=topupSuccess");

            } else if ("releaseEscrow".equalsIgnoreCase(action)) {
                int bookingId = Integer.parseInt(request.getParameter("bookingId"));
                // Atomic transaction: release escrow and disburse mentor earnings (95%)
                walletDAO.executeEscrowSettlement(bookingId, new BigDecimal("0.05"));
                response.sendRedirect("mySessions.jsp?status=sessionCompleted");

            } else if ("withdraw".equalsIgnoreCase(action)) {
                BigDecimal withdrawAmount = new BigDecimal(request.getParameter("amount"));
                String bankAccount = request.getParameter("bankAccount");
                walletDAO.debitWithdrawal(userId, withdrawAmount, "Payout to Bank: " + bankAccount);
                response.sendRedirect("mentorDashboard.jsp?status=withdrawalQueued");
            }
        } catch (Exception ex) {
            ex.printStackTrace();
            response.sendRedirect("error.jsp?error=" + ex.getMessage());
        }
    }
}
