# ElderEarn – Skill Sharing and Micro-Earning Platform

## Overview

ElderEarn is a modern, responsive web application designed to bridge generations by connecting skilled individuals with learners through an online learning and marketplace platform.

Teachers can publish skills, upload educational videos, sell digital and physical products, and earn income. Students can discover teachers, subscribe to courses, purchase products, watch learning videos, and communicate directly with mentors.
